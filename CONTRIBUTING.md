# Contributing

Open an issue or a pull request. One change per pull request.

The minute is the object. Do not add a map, a mode switcher, or a library to animate the number. The page stays static. No framework.

A new source should return the facts the board already draws: minutes, train number, line, place, and late. It should not get its own layout.

Do not commit credentials. No API keys, tokens, or passwords in the page, in a commit, or in an environment file. This repo has no .env. A keyed feed belongs on a server, not in this page.
